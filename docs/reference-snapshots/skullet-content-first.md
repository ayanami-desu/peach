# Skullet 与内容优先显示

取证日期：2026-11-07。本文是人工取证笔记，不作为上游原文快照登记。版本与摘要见 `docs/reference-sources.json` 的 `skullet-skeleton`；上游原文见 [包说明快照](upstream/skullet-skeleton.md)。

来源：[在线演示](https://skullet.lochie.me/)、[官方源码](https://github.com/lochie/skullet)。

## 实测

- 在线演示显示版本 `0.0.3`。重载文章卡时，仅该卡进入 `aria-busy`，其它示例继续显示。
- 官方 React `Skeleton` 在等待数据时渲染不可见的原组件或样本，通过测量生成文字行、图片和控件占位；`id` 可保存形状。
- 图片加载和解码独立等待，不阻挡文字。形状记忆清除媒体地址和表单值，填充函数替换英文和数字，但不替换中文；不能把任意用户文本的记忆视为匿名布局。退出账号时可调用 `forgetShapes`。
- `smart` 会避开短于 150 ms 的骨架闪现，可能按屏幕顺序入场；源码的顺序入场跨度为 320 ms，普通淡化为 200 ms。减少动态效果时保持静止。
- npm 发行版与演示均为 `0.0.3`，许可 MIT。包解压大小不代表 Peach 的实际增量体积。

## 与 Peach 的差异

| 能力 | Peach | Skullet |
| --- | --- | --- |
| 骨架形状 | 页面模板、真实布局类、`fitSkeleton` 与部分形状记忆 | 测量隐藏组件，按文字行和元素生成 |
| 图片等待 | 独立图片格与微光 | 独立图片占位及解码后的淡化 |
| 内容显示 | 区域由查询状态控制，专用模板保留页面控件 | 每个 `Skeleton` 边界按传入状态显示 |
| 形状检查 | 项目浏览器几何回归 | 调试轮廓与布局变化提示 |
| 顺序 | 本地内容到达即显示 | 可选择整体、顺序、扫入或自动策略 |

## 取舍

**推导：**自动测量不能解除外部的 `Promise.all` 或等待图片的取数函数。必须先拆开真正独立的查询及显示状态，再选择骨架生成方式。

Peach 保留馆藏网格、表格、播放舞台与已有表单的专用骨架，沿用 `AsyncText` 的原位尺寸和已有形状记忆。已就绪内容立即替换自身骨架，不为统一入场等待其它区域。权限、当前任务身份、复核对象及表单修订号仍按各自操作契约核实。

## Peach 适配

固定依赖 `skullet@0.0.3`。`MeasuredReading` 不接受任意子组件或自由文本，只渲染数值、固定单位和数字总数，避免隐藏渲染触发请求、Portal、播放器或操作副作用。形状键固定为字段名，不含用户身份；记忆只存数字占位和固定单位，不存作品名、路径和用户中文资料。

每格独立取得数据后立即显示，不使用顺序入场；150 ms 只抑制短暂骨架。骨架在上游 Shadow DOM 内绘制，通过构造样式表接入 Peach 的 1.5 s 微光和减少动效规则。样本隐藏不依赖 `@scope`，供旧版 Safari 使用。数据已存在时不因后台重读或重读失败重新盖上骨架；首次读取失败另显示「未取得」。固定标题保留在测量区外，供原位编辑。

适配构建相对同工作树接入前的产物，按需包增加约 22 KiB gzip，首页入口包基本不变；这是局部构建差额，正式合批后应以最终产物复核。测量边界固定六个，不随馆藏数量增加。桌面、390×844、浅深主题、独立等待和表格浮层已在真实小样本预览中查看；正式回归记录由交付批次签发。没有在 Safari、Firefox 或超大馆藏设备上取得实际运行证据，不将源码兼容处理等同于这些平台验收。
